Política de privacidad

Última actualización: 19 de octubre de 2026.

1. Responsable del sitio

Empieza Fácil es un sitio web de información práctica sobre organización del dinero, empleo y hábitos. Antes de utilizar este sitio con fines comerciales, se deben completar los datos de identificación y contacto del responsable.

2. Datos personales

Esta web no incluye actualmente formularios para recoger datos personales. El proveedor de alojamiento puede tratar datos técnicos necesarios para prestar el servicio, según sus propias condiciones y políticas.

3. Cookies y servicios externos

Si en el futuro se incorporan herramientas de análisis, publicidad u otros servicios que utilicen cookies o tecnologías similares, esta política se actualizará y se solicitará el consentimiento cuando sea necesario.

4. Enlaces de afiliados

Si se añaden enlaces de afiliados, se indicará claramente junto a ellos. El sitio podría recibir una comisión por compras que cumplan las condiciones del programa, sin coste adicional para el visitante.

5. Derechos de los usuarios

Las personas cuyos datos se traten podrán ejercer los derechos que les reconozca la normativa aplicable mediante el contacto del responsable, una vez que este se haya identificado en la web.

6. Contacto

Se añadirá un medio de contacto del responsable antes de utilizar el sitio para actividades comerciales.
