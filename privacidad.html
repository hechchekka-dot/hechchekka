Política de privacidad

Última actualización: 18 de octubre de 2026.

1. Responsable

Empieza Fácil es un sitio web de información práctica sobre organización del dinero, empleo y hábitos. Antes de publicar, completa esta sección con el nombre del responsable y un medio de contacto válido.

2. Datos personales

Este sitio no solicita datos personales mediante formularios en su versión actual. El proveedor de alojamiento, GitHub Pages, puede tratar datos técnicos necesarios para ofrecer el servicio, conforme a sus propias políticas.

3. Cookies y servicios externos

Este sitio puede incorporar servicios externos en el futuro, como enlaces de afiliados o herramientas de estadísticas. Si se añaden tecnologías que requieran información o consentimiento, esta política deberá actualizarse antes de activarlas.

4. Enlaces de afiliados

Si se incorporan enlaces de afiliados, se indicará claramente junto a ellos. El sitio podrá recibir una comisión por compras que cumplan las condiciones del programa, sin coste adicional para el visitante.

5. Derechos de las personas usuarias

Cuando se traten datos personales, las personas usuarias podrán ejercer los derechos que les correspondan conforme a la normativa aplicable contactando con el responsable.

6. Contacto

Para consultas sobre privacidad, utiliza el medio de contacto que se indique aquí cuando esté habilitado.
